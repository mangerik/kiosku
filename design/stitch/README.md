# Sumber desain

Proyek: [Kiosku Multi-Store SaaS — Google Stitch](https://stitch.withgoogle.com/projects/3226115365701511664).

Ekspor asli: `../../stitch_kiosku_multi_store_saas.zip` dari root proyek (`D:\kiosku\stitch_kiosku_multi_store_saas.zip`). Hasil ekstraksi ada di `export/stitch_kiosku_multi_store_saas/`.

- `dashboard.html` → dashboard_merchant/code.html
- `products.html` → manajemen_produk/code.html
- `builder.html` → pembangun_toko/code.html
- `wallet.html` → manajemen_saldo/code.html
- `storefront.html` → tampilan_toko_ruang_rupa/code.html

`export/.../kiosku/DESIGN.md` memuat design system asli. HTML di folder ini hanya referensi desain; aplikasi utama ada di `src/`. Foto demo frontend disimpan lokal di `public/images/`, bersumber dari Unsplash; logo dan aset rancangan Stitch disertakan dalam ekspor.
